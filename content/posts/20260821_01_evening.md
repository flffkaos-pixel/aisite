### 고성능 스텔스 모델 Ox Alpha가 무료 공개

- 1M 토큰의 컨텍스트 윈도우와 멀티모달 입력을 지원하는 스텔스 모델 “Ox Alpha”가 무료로 공개되었습니다.
- DeepSWE 벤치마크에서 Fable 5와 GPT‑5.6 Sol을 상회하는 점수를 기록했다고 보고되었습니다.
- 커뮤니티에서는 Zhipu AI의 차세대 모델(예: GLM‑5.4, 5.5 등)일 가능성이 있다는 추측이 나오고 있습니다.

> まつにぃ: 이게 어떤 스텔스 모델이야? Grok인가?  
> Lisan al Gaib: Ox Alpha는 ZAI / GLM 모델입니다.  
> Haider.: 와, 이 스텔스 모델 “Ox‑Alpha”가 DeepSWE에서 Fable 5와 GPT‑5.6 Sol을 압도한 것 같습니다. 대규모 아키텍처 작업에서는 아직 시험해 보지 않았지만, 오케스트레이터, 실행자, 리뷰어로서 충분 이상입니다. 확실히 5.6 Luna보다 한 단계 앞서 있습니다. 제 추측은 MiMo입니다.

### 로봇 기반 모델 “GEN‑1.5”가 One‑Shot 학습을 실현

### Claude의 Computer Use 및 Skills API가 GA에【연속 보도】

- Anthropic의 Claude Platform에서 “Computer Use” 등과 관련된 연속 보도입니다.
- Computer Use, Skills API, Files API가 일반 제공(GA)되었습니다.
- 한 턴에서 클릭, 타이핑 등 다중 액션을 실행할 수 있게 되었습니다.
- 태스크당 왕복 횟수가 20~40% 감소해 처리 속도와 API 사용 비용이 절감될 것으로 기대됩니다.

> Oikon | Claude Code 심층 가이드: Claude Platform에서 computer use를 포함한 도구 API에 대해 1턴마다 여러 액션(클릭, 타이핑, 키, 스크린샷)을 실행하도록 개선되어, 작업당 20‑40% 적은 왕복 횟수도 달성할 수 있다고 합니다. 그 결과 작업이 더 빨리 완료되고 비용도 절감됩니다.

### Grok Build가 모든 유료 사용자에게 공개【추가 보도】

### Azure OpenAI Design Patterns v3.5.0 출시

- Azure OpenAI의 아키텍처 설계 패턴 “v3.5.0”이 출시되었습니다.
- API Management(APIM)를 AI Gateway로 활용한 멀티 리전 페일오버와 우선순위 기반 라우팅 등이 구현되었습니다.
- 토큰 및 비용 가시화 등 엔터프라이즈용 실용적 업데이트로 개발자들로부터 평가를 받고 있습니다.
