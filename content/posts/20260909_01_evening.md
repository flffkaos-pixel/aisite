### LLM을 활용한 가상 고객으로 A/B 테스트 예측 방법

- Amazon의 연구자들이 LLM을 활용해 A/B 테스트 결과를 고정밀도로 예측하는 새로운 방법을 발표했습니다.
- 실제 사용자 행동 기록을 바탕으로 LLM으로 약 1,000명분의 “가상 고객”을 생성하고, 실제 사용자 테스트 전에 70~90%의 정밀도로 결과를 예측할 수 있다고 합니다.
- 사용자 피드백을 저비용·신속하게 얻는 수단으로 실무 적용이 기대됩니다.

> 준 나이토 / 내토 준: 꽤 방대한 데이터가 있어 외부 테스트가 더 쉬워질 것 같은데, 결국 오래전부터 사용자 피드백을 얼마나 저렴하게 얻는가라는 경쟁에서, LLM으로 대체 가능하고 여러 번 시도할 수 있다면 급속히 이게 디파クト가 될 것 같아. 우리 회사에서 연구해 볼까 AIDB: 관련 기사: “이 제품이 나오면 사나요?” 소비자 조사에서 인간 대신 LLM을 잘 활용하는 방법

### Claude Code 무료 이용을 주장하는 리포지토리 주의 촉구

- “Claude Code를 무료로 이용할 수 있다”는 주장을 하는 GitHub 리포지토리가 확산되고 있지만, 실제로는 진짜 Claude Code가 아니라는 주의가 전달되고 있습니다.
