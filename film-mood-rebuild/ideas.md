# Film Mood 재구축 디자인 기준

## 기준 참조

본 프로젝트는 사용자가 지정한 **https://yeguozi.com**을 시각적·구조적 기준으로 삼는다. 현재 배포본 **https://film-mood.pages.dev/** 및 저장소 **https://github.com/flffkaos-pixel/film-mood**와 비교하여, 참조 사이트에서 확인되는 콘텐츠 밀도, 이미지 배치, 섹션 순서, 여백, 인터랙션 및 타이포그래피의 인상을 가능한 범위에서 충실히 반영한다.

## 확정 접근: 레퍼런스 충실 재구축

- **디자인 운동**: 참고 사이트의 실제 편집형 디지털 매거진 / 작품 아카이브 문법을 그대로 해석한다.
- **핵심 원칙**: 원본의 정보 위계 보존, 이미지 주도 구성, 화면별 비례와 흐름의 재현, 불필요한 자체 스타일 추가 금지.
- **색상 철학**: 기존 CSS가 정의한 색상·토큰·기본 타이포그래피를 보존하며, 참조 사이트의 분위기는 이미지와 콘텐츠 구조로 전달한다.
- **레이아웃 패러다임**: 참조 사이트의 스크롤 흐름과 비대칭적 이미지 배열을 우선한다. 임의의 균일한 카드 그리드로 치환하지 않는다.
- **시그니처 요소**: 화면 폭을 활용한 시각 자료, 편집적 캡션 및 메타 정보, 절제된 탐색 요소를 참조 사이트에서 확인되는 방식으로 반영한다.
- **상호작용 철학**: 탐색과 열람을 방해하지 않는 범위에서 링크, 호버 및 필터 상태를 명료하게 표시한다.
- **애니메이션**: 참고 사이트에 존재하는 경우에만 짧고 절제된 전환을 구현한다. CSS 파일은 변경하지 않는다.
- **타이포그래피 시스템**: 현재 CSS가 제공하는 글꼴·크기·토큰을 유지하며, 정보 위계는 마크업 구조 및 기존 유틸리티 조합으로 조정한다.
- **브랜드 에센스**: 영화의 정서와 장면을 탐색하는 사용자에게, 감정 중심의 시각 아카이브를 제공하는 Film Mood.
- **브랜드 성격**: 감각적, 편집적, 절제된.
- **브랜드 보이스**: 짧고 관찰적인 문장으로 작품과 감정의 연결을 제안한다. 예: “오늘의 장면을 고르세요.” / “빛, 침묵, 그리고 한 편의 기억.”
- **워드마크 및 로고**: 기존 저장소 또는 현 배포본에 로고 자산이 있을 경우 이를 유지한다. 새 심볼이 필요하면 텍스트 없는 필름 프레임 기반의 단순한 표식을 사용한다.
- **시그니처 브랜드 색상**: 기존 CSS에서 이미 사용 중인 핵심 강조색을 유지한다.

## 변경 제약

1. 사용자의 명시적 요청에 따라 `client/src/index.css` 및 기존 CSS 파일을 수정하지 않는다.
2. 스타일 보정이 필요할 때에도 새로운 CSS 파일을 추가하지 않고, 기존 클래스·마크업·콘텐츠 및 외부 시각 자료의 교체를 우선한다.
3. 참조 사이트의 스크린샷 및 실제 로드된 이미지·구조를 확인한 뒤에만 구현 세부사항을 확정한다.

## Style Decisions

홈 화면의 첫 장면은 중앙 정렬 랜딩 히어로 대신, 대표 영화 스틸·짧은 관찰 문장·메타 정보가 비대칭적으로 놓이는 편집형 구성을 사용한다. 영화, 감독, 색상 컬렉션은 균일한 카드 그리드를 기본값으로 삼지 않으며, 큰 이미지와 작은 이미지, 캡션 블록 및 메타 라벨이 섞인 매거진형 배열을 우선한다. 브랜드 문장은 설명형 홍보 문구보다 빛, 색, 공간, 기억을 관찰하는 짧은 문장을 유지하고, 각 섹션은 단순한 분류가 아니라 큐레이션의 시선을 드러낸다.
