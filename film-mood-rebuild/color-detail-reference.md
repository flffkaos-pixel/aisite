# Red 색상 상세 페이지 참조 사양

`https://www.yeguozi.com/en/colors/red`는 어두운 편집형 화면에서 색상 스와치, 색상명, 해당 색상으로 분류된 영화·스크린샷 수, 짧은 설명을 한 묶음으로 먼저 제시한다. 이어서 비슷한 색과 보색으로 이동하는 색상 칩을 제공하고, 프레임별 팔레트를 보이거나 숨기는 제어 및 그리드·영화별·큰 흐름 보기 전환을 배치한다.

핵심 콘텐츠는 넓은 비대칭 프레임 그리드다. 각 스틸은 영화명 캡션, 저장 동작, 이미지에서 추출한 다수의 색상 칩과 비율을 함께 표시한다. 구현에서는 현재 CSS를 수정하지 않으며, 기존 `#/color/red` 경로에 색상 헤더, 유사 색상 링크, 표시 모드 제어, 다층 프레임 갤러리, 이미지 확대 동작을 복원한다.

## 정확 이전 조사 메모

Red 원본 페이지는 현재 브라우저에서 실제 프레임과 팔레트가 렌더링되지만, 정적 HTML 추출본에는 로딩 골격만 포함되어 있어 전체 프레임 URL 목록이 그대로 노출되지 않았다. 공개 `yeguozi` GitHub 계정의 저장소 두 개는 해당 서비스의 데이터 저장소가 아니었다. 따라서 다음 단계에서는 원본 페이지가 화면에 로드한 프레임 URL을 직접 수집하거나, 사용자가 가진 원본 프레임 데이터·내보내기 자료를 받아야 전체 순서를 정확하게 일치시킬 수 있다.
